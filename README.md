# SIDE B｜深夜唱片室

SIDE B 是一個以華語流行音樂黑膠收藏為主題的互動網頁。使用者可以瀏覽專輯封面、展開整張專輯的曲目，並選歌播放官方短版試聽。

- 公開網站：[SIDE B 黑膠聆聽室](https://erickuo0707.github.io/-Homework-for-the-fifth-week/)
- 網頁入口：index.html
- 實作方式：HTML、CSS 與 JavaScript 集中在單一 HTML 檔案，專輯封面與試聽音源由 Apple Music 提供。

## 規格書

### 主題與目標使用者

打造一間深夜風格的線上黑膠聆聽室，讓喜歡華語流行音樂的使用者能以逛唱片櫃的方式挑選歌手與專輯，查看完整曲目並試聽歌曲。

### 功能需求

1. **立體唱片堆**：十張專輯封面以有厚度的實體封套前後堆疊，卡片層距拉開並以透視與側邊陰影呈現厚度；在唱堆上滾動滑鼠滾輪或使用上下按鈕／方向鍵，逐張切換唱片。
2. **抽出專輯**：點選唱堆中可見的封面，該張唱片會向前滑出並展開完整曲目清單；再次點選已抽出的封面或以滾輪切換時，唱片會收回唱堆。滑鼠懸停時封套與黑膠也會微幅錯位，呈現可翻閱的手感。
3. **專輯曲目**：點選專輯卡片會在右側播放佇列展開該專輯完整曲目清單；選歌前不會自動播放。
4. **唱盤動畫**：點選曲目後，唱片飛到唱盤並以 33⅓ RPM（每圈約 1.8 秒）持續轉動；唱片標籤、溝槽反光與外圈定位點會一起轉，讓旋轉容易辨認。唱臂移到唱片外圈溝槽並放下唱針；暫停時唱片停在當下角度、唱針抬起，繼續播放後接著轉；試聽結束則停止唱片。
5. **歌曲播放**：播放 Apple Music 提供的官方短版音訊試聽。可使用播放器控制播放或暫停。
6. **專輯內切歌**：「下一首」會播放目前專輯的下一首曲目。
7. **搜尋**：可搜尋專輯名稱、歌手名稱或曲名；曲目清單會同步顯示符合關鍵字的歌曲。
8. **歌手篩選**：可依女聲、男聲或全部收藏篩選專輯。
9. **Apple Music 連結**：選歌後才啟用「在 Apple Music 開啟」，直接前往該歌曲的 Apple Music 頁面。
10. **響應式版面**：桌面以唱片櫃、唱盤和播放佇列三區並排；窄螢幕時改為上下排列，唱堆可用上下按鈕瀏覽。
11. **易讀介面**：介面文字最小字級調整為 11px，並保留按鈕鍵盤操作焦點樣式。
12. **唱盤外型**：依照實體唱片機照片，使用一致的斜俯視角呈現霧黑機身、厚實前面板、金屬盤緣、橡膠腳墊與掀起的透明防塵蓋。右側唱臂具配重、支架、唱頭與唱針；整台依相同比例縮放，手機版也能讓唱針落在黑膠外圈。

### 介面配置

- **頂部**：SIDE B 品牌、播放空間狀態與頁面標題。
- **左側唱片櫃**：收藏數量、歌手篩選、搜尋欄、滾輪位置指示和立體疊放的專輯封面。
- **中央唱盤**：目前播放歌曲、黑色長方形唱盤機身、左側唱片與右側唱臂，機身後方可見掀起的半透明防塵蓋；下方提供播放控制、音訊播放器與 Apple Music 連結。
- **右側播放佇列**：顯示選定專輯的完整曲目，點選曲目即可播放試聽。
- **頁尾**：網站主題與封面、試聽音源來源說明。

### 互動流程

1. 開啟網站後瀏覽唱片櫃，也可以先使用搜尋或歌手篩選。
2. 在唱堆上滾動滑鼠滾輪切換封面，也可按上下按鈕或方向鍵；點選一張唱片，觀看它從唱堆抽出並展開曲目。
3. 點選想聽的歌曲，唱片移至唱盤並載入該曲的試聽音源。
4. 使用播放控制聆聽或暫停；點選「下一首」切換到同張專輯的下一曲。
5. 點選「在 Apple Music 開啟」可前往該首歌曲的 Apple Music 頁面。

### 音源與使用限制

所有音源皆為 Apple Music 提供的短版試聽（約 30 秒），播放需要網路連線。
